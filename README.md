# Playwright Todo Tests

Автотесты для веб-приложения TodoMVC. Учебный проект для освоения автоматизации тестирования.

## Технологии

- Playwright
- TypeScript

## Что покрыто тестами

- Добавление задачи
- Негативный тест: пустая задача не добавляется
- Удаление задачи
- Удаление одной задачи из нескольких (поиск по тексту)
- Параметризованные тесты на разных данных
- Отметка задачи как выполненной

## Структура проекта

- `tests/Todo.spec.ts` — тесты
- `tests/TodoPage.ts` — Page Object страницы TodoMVC
- `playwright.config.ts` — конфигурация Playwright
- `.github/workflows/` — настройка CI

## Запуск

```
npm install
npx playwright test
```

## CI

Тесты запускаются автоматически через GitHub Actions при каждом push.
